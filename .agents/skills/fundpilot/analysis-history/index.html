FundPilot 日度持仓分析历史目录

本目录用于存放周期性 Agent 生成的日度持仓分析报告。报告应长期保留，便于用户回看每次分析时的持仓、行情、资讯和建议依据。

文件命名

  • 标准命名：YYYY-MM-DD-daily-position-analysis.html
  • 同一天多次生成：YYYY-MM-DD-daily-position-analysis-2.html
  • 文件必须使用 UTF-8 编码。

生成步骤

  1. 读取 ../templates/daily-position-analysis-template.html。
  2. 调用 FundPilot CLI 获取持仓、计划、策略、操作记录和今日信号。
  3. 如 Agent 具备搜索工具，按用户持仓和偏好检索当天或最新相关资讯，并写入来源链接；无搜索工具时写明“本次未检索外部资讯”。
  4. 将报告保存到本目录。
  5. 更新 ../index.html 的历史分析列表，把最新报告链接放在最前。

固定分析结构

  1. 一句话结论
  2. 数据来源与缺口
  3. 持仓概览
  4. 单只基金诊断
  5. 行情与风格观察
  6. 相关资讯摘要
  7. 操作建议与资金纪律
  8. 风险提示
  9. 下次观察点

合规要求

  • 不使用“必买”“稳赚”“保证”“一定”等保证性表述。
  • 不编造净值、涨跌幅、资讯标题或来源链接。
  • 建议必须可追溯到持仓数据、行情信号、操作记录或已标注来源的资讯。
  • 报告只作为投资分析辅助，不替用户做最终投资决策。
