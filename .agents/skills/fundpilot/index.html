周期性 Agent 每次完成持仓分析后，将报告写入 analysis-history/，并在本页追加历史链接。

生成约定

  1. 读取 templates/daily-position-analysis-template.html。
  2. 结合持仓、行情、策略信号、操作记录和可检索资讯生成简洁报告。
  3. 保存为 analysis-history/YYYY-MM-DD-daily-position-analysis.html。
  4. 在“历史分析”列表顶部追加该报告链接。

分析边界

报告只能作为投资分析辅助，不提供保证性结论；若行情接口或资讯检索不可用，必须在报告中说明缺口，不得编造数据。
